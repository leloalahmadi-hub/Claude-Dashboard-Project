# لوحة إدارة المشاريع (Claude Dashboard Project)

لوحة تحكم عربية (RTL) حديثة لإدارة ومتابعة المشاريع — مبنية بالكامل بـ **HTML وCSS وJavaScript فقط** (بدون أي Frameworks أو مكتبات خارجية)، ومرتبطة بقاعدة بيانات حقيقية عبر **Airtable** من خلال خادم Node.js وسيط يحمي بيانات الاتصال.

## ✨ المزايا

- **نظرة عامة**: بطاقات إحصائية حيّة (الإجمالي، النشطة، المكتملة، المتأخرة)، أحدث المشاريع، تنبيهات سريعة (مشاريع متأخرة / تحتاج متابعة / قريبة من التسليم)، وتوزيع المشاريع حسب الحالة والإدارة.
- **المشاريع**: بحث، فلترة حسب الحالة والأولوية، وإضافة/تعديل/حذف مع تحقق كامل من صحة المدخلات.
- **المسؤولون**: إحصائيات لكل مسؤول (عدد المشاريع، النشطة، المكتملة، المتأخرة، متوسط الإنجاز) مع عرض مشاريعه عند اختياره.
- **الإدارات**: إضافة إدارة جديدة، وبطاقة لكل إدارة تلخّص مشاريعها وحالتها.
- **التحليلات**: توزيعات مرئية حسب الحالة والأولوية والإدارة، ومتوسط الإنجاز العام.
- **الوضع الداكن / الفاتح** مع الحفظ التلقائي للتفضيل.
- تصميم متجاوب بالكامل (جوال، تابلت، سطح مكتب).

## 🏗️ البنية التقنية

| الطبقة | التقنية |
|---|---|
| الواجهة (Frontend) | HTML + CSS + JavaScript خالص، بدون Frameworks |
| الخادم الوسيط (Backend) | Node.js (وحدة `http` المدمجة فقط — بدون أي حزمة خارجية) |
| قاعدة البيانات | Airtable (جدول Projects) |

### لماذا خادم وسيط؟
المتصفح لا يتصل بـ Airtable مباشرة أبدًا. كل طلب يذهب إلى الخادم المحلي (`server.js`)، وهو من يحمل توكن Airtable من متغيرات البيئة (`.env.local`) ويتصل بـ Airtable نيابة عن الواجهة. هذا يمنع ظهور التوكن في المتصفح أو الـConsole أو Network tab نهائيًا.

## 📁 هيكل الملفات

```
project-dashboard/
├── index.html                        # هيكل الصفحة
├── style.css                         # كل التنسيقات (فاتح/داكن، تجاوب)
├── app.js                            # منطق الواجهة والتفاعل
├── dataService.js                    # طبقة البيانات — تتحدث مع /api/* فقط
├── data.js                           # بيانات تجريبية أولية (احتياطية)
├── server.js                         # الخادم الوسيط + الاتصال بـ Airtable
├── dataService.localStorage.backup.js# نسخة احتياطية تعمل بـ localStorage بدون خادم
├── package.json
└── .env.local                        # بيانات الاتصال (غير مرفوع — راجع .gitignore)
```

## 🚀 التشغيل محليًا

1. ثبّت [Node.js](https://nodejs.org) (نسخة 18 أو أحدث).
2. أنشئ ملف `.env.local` في جذر المشروع وأضف فيه:
   ```
   AIRTABLE_BASE_ID=appXXXXXXXXXXXXXX
   AIRTABLE_TOKEN=patXXXXXXXXXXXXXX...
   ```
3. شغّل الخادم (لا حاجة لـ `npm install` — لا اعتماديات خارجية):
   ```bash
   node server.js
   ```
4. افتح المتصفح على: `http://localhost:3000`

## 🔒 الأمان

- `.env.local` مستبعد بالكامل عبر `.gitignore` — لا يظهر في هذا المستودع إطلاقًا.
- التوكن يُقرأ فقط من طرف الخادم (`process.env`)، ولا يُرسَل أو يُطبَع في أي استجابة يراها المتصفح.
- كل طلبات الواجهة تمر عبر `/api/...` المحلي فقط.
